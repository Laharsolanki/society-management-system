# 🏘️ Society Management System

Full-stack application for residential society management.

## Features
- User Authentication (JWT)
- Amenity Booking System
- Expense Tracking
- Member Management

## Tech Stack
- Backend: Node.js, Express, PostgreSQL
- Frontend: React, Tailwind CSS
- ML: Python, Flask
